## 3. Méthode d'inventaire

Projets `medisphere`, `plateforme`, `bibliotheque`, étiquettes `v*` (en service ou récentes). Source : **SBOM SPDX attestées**, vérifiées avec `docs/registre/cosign.pub` (`cosign verify-attestation --type spdxjson --insecure-ignore-tlog=true`) ; recherche sur le nom **normalisé** (`prometheus-client` = `prometheus_client`). Limites : les caches publics n'ont pas d'attestation (non concernés ici : aucune image Python des caches n'est exécutée telle quelle) ; les images sans attestation auraient été réanalysées avec Syft.
