## Préparation
- [ ] Export vérifié (manifestes + sommes du courriel) — `inspecter-export.sh`
- [ ] Flux ouverts dans `group_vars/role_routeur/pare_feu.yml` et le pare-feu local (MR)
- [ ] Code prêt : `envs/f4-infoger` (sans les blocs `import` tant que les VMs n'existent pas), Ansible, répartiteurs
- [ ] Communication : partenaires (J-7), cabinets (J-7, bandeau)

## Étapes (par VM)
1. `convertir-vm-infoger.sh --vm <nom> --cle /root/cle-admin.pub --sommes <courriel>` sur `pve01`.
2. `tofu apply` de `envs/f4-infoger` (import, NetBox, DNS), puis `tofu plan` vide.
3. Pipeline Ansible `playbooks/f4-infoger.yml` (supervision, journaux, pare-feu local, mises à jour).
4. Vague 2 seulement : publication de `rdv` par les répartiteurs (`lb02` puis `lb01`).
5. Travail de sauvegarde PBS `f4-infoger`, première sauvegarde manuelle.
6. Contrôles de succès, mesures, `lab/bin/check F4 10`.

## Go / no-go
